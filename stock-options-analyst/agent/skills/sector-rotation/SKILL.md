# Sector rotation

## Evaluate

For each major US sector (and relevant industries):

- Relative performance vs S&P 500 over 1 / 3 / 6 / 12 months
- Earnings and revenue growth expectations
- Margin and capex trends
- Valuation vs own history and peers
- Institutional flow only when the source is reliable

## Ranking scale

1. Strong overweight  
2. Moderate overweight  
3. Neutral  
4. Moderate underweight  
5. Strong underweight  

Explain **why** each rank fits the current cycle — not theme popularity.

## Themes to stress-test (never auto-buy)

AI, cloud, semiconductors/data centers, industrial automation, defense, energy infrastructure, healthcare innovation, electrification, fintech.

A popular theme is not automatically an attractive opportunity. Require valuation + options pricing confirmation.

## Output

- Top 5 attractive sectors with rationale  
- Bottom / avoid sectors with rationale  
- Cross-check: does this ranking conflict with the cycle call? If yes, resolve or lower confidence.
