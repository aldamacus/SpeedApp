# Challenge the recommendation

For every shortlisted company or trade, write:

## Bull case
What has to go right (macro, company, multiple, volatility)? Rough upside path.

## Base case
Most likely path given current evidence. Aligns with the recommended structure.

## Bear case
How the thesis fails. Include macro shock, company-specific, and vol/liquidity failure modes.

## Invalidation checklist
List concrete, observable triggers that would force **WAIT**, **AVOID**, or exit — e.g. cycle reclassification, earnings miss + guidance cut, technical breakdown below a named level, IV crush / expansion beyond assumption, credit spread spike, sector thesis break.

## Bias audit
- What confirming evidence did you overweight?
- What contradictory evidence did you discount?
- Are you recommending a trade because you need to fill the report? If yes → **NO TRADE**.
